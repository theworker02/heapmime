# heapmime

Heap encode/decode helpers for mime payloads in pipelines.

**Site:** https://theworker02.github.io/heapmime/

## Install / run

```bash
git clone https://github.com/theworker02/heapmime.git
cd heapmime
node src/cli.js
node --test
```
